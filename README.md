# 🏏 T20 World Cup Performance Analytics Dashboard

## Overview

The **T20 World Cup Performance Analytics Dashboard** is a Business Intelligence solution developed using **Excel, SQL, Python, and Power BI** to analyze ICC T20 World Cup data and uncover meaningful insights into player performance, team strategies, and tournament outcomes.

The dashboard transforms raw cricket data into interactive visualizations and executive-level insights, enabling analysts, coaches, and cricket enthusiasts to evaluate batting, bowling, and team performance through key performance indicators and data-driven analytics.

---

# Business Problem

Modern cricket generates a vast amount of match and player statistics. However, raw data alone provides limited value without structured analysis.

Cricket analysts and decision-makers often face challenges such as:

* Identifying consistent player performances across tournaments
* Comparing batting and bowling efficiency between teams
* Evaluating team strengths and weaknesses
* Measuring player contributions using performance metrics
* Extracting actionable insights from large volumes of match data

Without an integrated analytical solution, it becomes difficult to make informed decisions based on historical performance.

---

# Solution

This project delivers an interactive analytics dashboard that converts ICC T20 World Cup match data into meaningful business insights.

The dashboard enables stakeholders to:

* Analyze player performance across tournaments
* Compare team statistics and match outcomes
* Evaluate batting and bowling efficiency
* Identify top-performing players
* Monitor team consistency
* Explore tournament trends through interactive dashboards
* Support data-driven sports analysis

# Key Performance Indicators

The dashboard monitors the following business metrics:

| KPI                  | Description                            |
| -------------------- | -------------------------------------- |
| Total Matches        | Total matches played in the tournament |
| Total Teams          | Number of participating teams          |
| Total Players        | Players included in the analysis       |
| Total Runs           | Aggregate runs scored                  |
| Total Wickets        | Aggregate wickets taken                |
| Average Strike Rate  | Batting efficiency across players      |
| Average Economy Rate | Bowling efficiency across teams        |
| Team Win Percentage  | Overall team success rate              |

# Installation

Clone the repository:

```bash
git clone(https://github.com/RAMAPRIYAM268/T20-WORLD-CUP-ANALYSIS.git)
```

Navigate to the project directory:

```bash
cd T20-WORLD-CUP-ANALYSIS
```

Install the required Python libraries:

```bash
pip install -r requirements.txt
```

Open the project components:

* Execute SQL scripts for data preparation.
* Run Python notebooks for data analysis and visualization.
* Open the Power BI dashboard (`.pbix`) for interactive exploration.
